# Didar Stuttgart — Kontaktseite

Ganz einfache Einseiter-Website: Logo, Name, Stadt, kurzer Text und ein Telegram-Kontakt-Button. Gedacht als Startpunkt, den du später ausbauen kannst.

## Dateien

- `index.html` — die Seite
- `logo.png` — dein hochgeladenes Logo (muss **im selben Ordner** wie `index.html` liegen)

## Live schalten (GitHub Pages)

1. Neues Repository erstellen, z. B. `didar-stuttgart`.
2. `index.html` und `logo.png` gemeinsam hochladen (gleicher Ordner!).
3. Im Repository zu **Settings → Pages** gehen.
4. Unter „Build and deployment" → **„Deploy from a branch"**, Branch `main`, Ordner `/ (root)`, speichern.
5. Nach ein bis zwei Minuten erreichbar unter:
   `https://<dein-nutzername>.github.io/didar-stuttgart/`

## Anpassen

- **Telegram-Link**: aktuell `https://t.me/Didar_stuttgart` — im `<a href="...">` in `index.html` austauschbar.
- **Text**: der Absatz unter dem Stadtnamen ist frei editierbar.
- **Farben**: aus deinem Logo übernommen — Olivgrün, Salbei, Sandton, Cremeweiß (als CSS-Variablen ganz oben im `<style>`-Block, leicht anpassbar).

## Später erweitern

Wenn du mehr Inhalte hast (Über uns, Termine, Mitgliedschaft, Galerie), sag einfach Bescheid — dann bauen wir die Seite zu einer vollständigen Website mit denselben Logo-Farben aus.
